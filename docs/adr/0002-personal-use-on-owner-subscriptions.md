# Personal use only, powered by the owner's subscriptions

The app has exactly one owner, runs only on their Mac, and calls AI through the owner's existing AI subscriptions, not paid API keys. That rules out accounts, billing, usage tiers, a hosted key proxy and Windows support, all of which the reference app has. A future reader should not add a server or API key plumbing "to finish the clone". Those features were deliberately left out.

Within those limits, the goal is to match HeyClicky's behavior as closely as possible. Where a constraint forces a gap, the spec names the gap and the closest substitute.
